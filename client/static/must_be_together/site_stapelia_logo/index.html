Почерпная

Dipper section

           

 

                      

 

 

 

Почерпная , это место где можно почерпнуть содержимое сайта дополнительным способом. Записи нужно читать по одной, а в почерпную вынесены и распределены броские, запоминающиеся части их содержимого. Это своего рода галерея, в которой можно нажать на картинку и увидеть её полностью, и дополнительно список записей где она появляется. Список напоминает комментарии, но не обманывайтесь, этот сайт целиком, есть театр одного актёра - меня.

The dipper section is for taking a deeper look quicker. Posts have to be read one by one while the dipper section has all the catchy and memorable content arranged and ready. It’s a gallery of sorts where one could click on a picture and see the full version of it, along with the list of posts it was included in. One might take this list for a list of comments but make no mistake, this site in its entirety is a one man show. And the man is me.

Записи

Posts

Записи это нумерованые публикации. Они предназначены для важных уведомлений, из них формируется RSS, и я стараюсь сохранять их неизменность. Если запись нужно изменить, я отображаю изменения подражая системе контроля версий. К изменённой записи прикрепляется чистовая версия, её ссылка отображается значком ниже.

                       

 

Posts are numbered publications. They are meant for important notifications. RSS is derived from them and I try to keep them persistent. When an edit is required I display changes by imitating a Version Control System. The latest version is attached to the edited post and the link looks like the image above.

Linux

На Linux hticExt не требует установку. Скопируйте исполняемый файл в папку, находящуюся в вашем PATH. После этого программу можно запустить, указывая файл настроек.

On Linux hticExt does not require installation. Just copy the executable into a directory in your PATH. To run the program use the command that provides the settings file.

hticExt.bin settings.json

Зачем расширение .bin у исполняемого файла hticExt?

Why does the executable of hticExt have the .bin extention

Расширение .bin у исполняемого файла hticExt продиктовано ограничениями Nekoweb. Без расширения файл будет ошибочно раздаваться как страница html. После скачивания файл можно переименовать.

The .bin extention of the executable of hticExt is dictated by limitations of Nekoweb. Without the extention the file would be wrongly served as html. Downloaded file could be renamed.
