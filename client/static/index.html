Windows

Установка hticExt на Windows

Installation of hticExt on Windows

перейти / open

Linux

На Linux hticExt не требует установку. Скопируйте исполняемый файл в папку, находящуюся в вашем PATH. После этого программу можно запустить, указывая файл настроек.

On Linux hticExt does not require installation. Just copy the executable into a directory in your PATH. To run the program use the command that provides the settings file.

hticExt.bin settings.json

Зачем расширение .bin у исполняемого файла hticExt?

Why does the executable of hticExt have the .bin extention

Расширение .bin у исполняемого файла hticExt продиктовано ограничениями Nekoweb. Без расширения файл будет ошибочно раздаваться как страница html. После скачивания файл можно переименовать.

The .bin extention of the executable of hticExt is dictated by limitations of Nekoweb. Without the extention the file would be wrongly served as html. Downloaded file could be renamed.
