Комманды исполняются в рамках заданного режима. Режимов 5: replace, append, erase или backspace, eraseLeft или delete, rewrite.

/d1000; /d0; /d50;

append дописывает содержимое в конец нода-назначения, не изменяя уже имевшееся содержимое.

/d1000; /d0; /d50;

replace мгновенно полностью стирает предыдущее содержимое и заменяет его новым.

/d1000; /d0; /d50;

erase он-же backspace посимвольно стирает содержимое нода-назначения, начиная справа. Количество стёртых символов равно количеству символов(и нодов) в ноде-предписании.

/d1000; /d0; /d50;

eraseLeft он-же delete посимвольно стирает содержимое нода-назначения, начиная слева. В остальном повторяет erase.

/d1000; /d0; /d50;

rewrite это комбинация append и eraseLeft. Этот режим создаёт пустую копию нода-назначения и вставляет её перед нодом назначения. Затем поочерёдно(с минимальной задержкой) выполняет комманду append на новом ноде-назначении, и комманду eraseLeft на старом ноде-назначении. Содержимое старого нода-назначения будет полностью удалено. Оба режима выполняются в одном контексте, и потому комманды нода-предписания, содержащего информацию для append влияют и на eraseLeft. Нодом-предписанием для eraseLeft служит копия старого нода-назначения, создаваемая автоматически. Так как комманды для append влияют на оба режима, дополнительные комманды для eraseLeft в автоматически созданном ноде-предписании не создаются. за ненадобностью.

/d50;

Commands are executed in accordance with the set mode. There are 5 modes: replace, append, erase a.k.a. backspace, eraseLeft a.k.a. delete, rewrite.

/d1000; /d0; /d50;

append writes new content after the existing content of the destination node. The existing content remains intact.

/d1000; /d0; /d50;

replace instantly and completelly erases the previous content of the destination node to then replace it with the new content.

/d1000; /d0; /d50;

erase a.k.a. backspace performes a symbol-wise removal beginning from the right. The number of erased symbols equals to the number of symbols in the prescription node.

/d1000; /d0; /d50;

eraseLeft a.k.a. delete performes a symbol-wise removal beginning from the left. Otherwise is the same as erase.

/d1000; /d0; /d50;

rewrite is a combination of append and eraseLeft. This mode first creates an empty clone of the destination node and inserts it before the destination node. It then alternates commands with minimal delay. It applies append on the new destination node and eraseLeft on the old destination node. The content of the old destination node will eventually be erased completelly. Both mode-commands are executed in the same context so the prescription for append affects eraseLeft also. The prescription for eraseLeft is the automatically created copy of the old destination node. Given how commands for append affect eraseLeft there is no need for extra commands in the automatically created prescription for eraseLeft.
